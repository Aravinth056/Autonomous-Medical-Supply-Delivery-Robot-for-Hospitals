# Results

The MediRoute robot was tested to evaluate obstacle detection, navigation, turning, payload capacity and battery performance.

## Obstacle Detection Test

| Trial | Initial Distance (cm) | Stop Distance (cm) | Result |
|---|---:|---:|---|
| 1 | 30 | 16.2 | Pass |
| 2 | 25 | 15.8 | Pass |
| 3 | 20 | 14.9 | Pass |
| 4 | 35 | 16.5 | Pass |
| 5 | 15 | 14.5 | Pass |

The robot successfully detected and stopped for obstacles in all trials.
