# CAD Design

This folder contains the CAD and mechanical design information of the MediRoute autonomous medical supply delivery robot.

## Mechanical Design

The robot uses a compact two-wheel differential drive system with a front caster/free wheel.

The chassis is designed with two levels:

- Lower level for motors, wheels, and battery
- Upper level for electronic components, LCD, and medical supply storage

## Main CAD Components

- Robot chassis
- Motor mounting arrangement
- Wheel arrangement
- Battery mounting
- Electronics mounting
- Medical supply storage compartment
- IR sensor mounting
- Ultrasonic sensor mounting
- LCD mounting

## Design Features

- Compact and lightweight structure
- Two-wheel differential drive
- Front caster support
- Separate storage compartment
- Easy access to electronic components
- Suitable for indoor hospital corridor movement

## Materials

The prototype chassis was developed using lightweight cardboard reinforced with acrylic components.

## CAD Files

CAD model files and design images can be added to this folder when available.

Example file names:

- `robot-chassis`
- `motor-mount`
- `storage-compartment`
- `complete-assembly`

## Purpose

The CAD design was developed to support the fabrication and assembly of the MediRoute autonomous medical supply delivery robot.
