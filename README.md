# Autonomous Medical Supply Delivery Robot for Hospitals

## 📌 Project Overview

The Autonomous Medical Supply Delivery Robot is designed to transport medicines, medical supplies and essential materials within hospitals with minimal human intervention.

The robot is intended to reduce repetitive manual transportation work, improve delivery efficiency and support hospital staff in moving supplies between different locations.

## 🎯 Objectives

- Automate transportation of medical supplies inside hospitals
- Reduce manual handling and repetitive transportation work
- Enable autonomous movement between predefined locations
- Improve delivery efficiency and reliability
- Develop a compact and cost-effective robotic platform

## ⚙️ Main Features

- Autonomous navigation
- Obstacle detection and avoidance
- Medical supply carrying compartment
- Motorized differential-drive system
- Sensor-based navigation
- Microcontroller-based control
- Rechargeable battery system
- Emergency/manual control option

## 🏗️ System Architecture

The system consists of:

1. Power Supply
2. Microcontroller
3. Motor Driver
4. DC Motors
5. Navigation Sensors
6. Obstacle Detection Sensors
7. Delivery Compartment
8. Control System

## 🔄 Working Principle

1. The user selects the required destination.
2. The robot receives the destination command.
3. Sensors continuously monitor the surroundings.
4. The controller processes sensor information.
5. The robot moves toward the destination.
6. Obstacles are detected during movement.
7. The robot changes its path when required.
8. The robot reaches the required location.
9. Medical supplies can then be collected or delivered.
