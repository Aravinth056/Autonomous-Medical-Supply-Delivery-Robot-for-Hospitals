## 📌 Project Overview

The Autonomous Medical Supply Delivery Robot is a mobile robotic system developed to transport medicines and essential medical supplies within hospital environments.

The robot is designed to move between predefined locations while carrying lightweight medical materials. It uses a microcontroller, motors and sensors to control movement and detect obstacles.

The main aim of this project is to reduce repetitive manual transportation work, save time and support hospital staff in delivering supplies efficiently.

This project combines mechanical design, CAD modelling, electronics, embedded programming and robotics to develop a compact autonomous delivery system.
