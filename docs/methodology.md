# Project Methodology

## 📌 Overview

The MEDIROUTE project follows a systematic methodology for designing, fabricating and evaluating an autonomous medical supply delivery robot.

The methodology combines literature review, problem identification, system design, hardware development, embedded programming, prototype fabrication, calibration and experimental testing.

---
