# Project Images

This folder contains images related to the MediRoute autonomous medical supply delivery robot.

## Images Included

- Robot prototype
- Arduino UNO
- IR sensor modules
- HC-SR04 ultrasonic sensor
- L298N motor driver
- DC gear motors
- Battery pack
- 16x2 LCD
- Robot chassis
- Medical supply storage compartment
- MediRoute hospital dispatch website
- Testing and demonstration

## Project Prototype

Images of the developed MediRoute robot prototype and its major components are stored in this folder.

## Usage

Images can be used in the main project README and documentation to show the robot design, hardware arrangement, website interface, and testing process.
